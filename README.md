# Result Management System

## Run with XAMPP

1. Copy this project folder into `C:\xampp\htdocs` and name it `result-management-system`.
2. Start **Apache** and **MySQL** in the XAMPP Control Panel.
3. Open `http://localhost/phpmyadmin`, choose **Import**, and select `database.sql`.
4. Visit `http://localhost/result-management-system/`.

## Demo administrator account

- Username: `admin`
- Password: `admin123`

The database includes two students and sample results. Students can search by roll number on the home page.
